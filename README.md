# Varun Gohil — Personal Website

Static personal site modeled after [suvinay.github.io](https://suvinay.github.io/), with content migrated from the previous al-folio Jekyll site in `../varungohil.github.io`.

## Structure

- `index.html` — Home
- `work/` — Research / experience
- `publications/` — Full publication list
- `blog/` — Blog posts
- `styles.css` — Shared stylesheet (Skeleton-based layout)
- `images/` — Profile photo and other images
- `docs/cv.pdf` — CV
- `pubs/` — Local paper PDFs
- `.nojekyll` — Disable Jekyll on GitHub Pages

## Local preview

```bash
cd varungohil-site
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## Deploy

Push this folder’s contents to the `main` (or `gh-pages`) branch of a GitHub Pages repo, or replace the contents of `varungohil.github.io` when ready to switch.
